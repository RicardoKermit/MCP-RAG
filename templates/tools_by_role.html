Ferramenta Descrição / Função Principal
set_model(model_name) Define o modelo de linguagem ativo (Gemini, OpenAI ou Ollama).
get_current_model() Retorna o modelo atualmente selecionado.
set_rag_backend(backend) Define o backend RAG (Qdrant ou Chroma).
get_rag_backend() Obtém o backend RAG atualmente configurado.
download_and_add_pdf(file_url) Faz o download de um ficheiro PDF a partir de um URL (geralmente proveniente do Moodle) e envia-o para indexação.
clear_rag() Limpa a base vetorial e remove todos os embeddings armazenados.
assign_role(email, role) Atribui um papel (Admin, Professor ou Aluno) a um utilizador.
list_users(limit) Lista os utilizadores registados no sistema.
deactivate_user(email) Desativa um utilizador e bloqueia o respetivo acesso.
export_logs() Exporta registos de operação da tabela operation_logs para auditoria.
system_health_check() Verifica o estado geral do sistema (base de dados, RAG, Moodle, disco).
add_new_pdfs() Procura novos ficheiros PDF disponíveis no diretório configurado e adiciona-os ao RAG.
download_pdfs_from_course(course_fullname) Recolhe automaticamente todos os PDFs de um curso Moodle e processa-os para integração no RAG.
analyze_student_queries() Analisa padrões de perguntas colocadas pelos alunos para identificar dificuldades frequentes.
generate_quiz_with_difficulty(topic, num_questions, difficulty) Gera questionários personalizados com base num tema, número de questões e nível de dificuldade.
practice_quiz(topic) Gera exercícios de prática rápida sobre um tema selecionado.
recommend_reading_material(topic) Sugere materiais de leitura complementares (artigos, vídeos, livros).
retrieve(prompt) Recupera informação diretamente dos PDFs indexados (base de conhecimento).
generate_dev_questions(topic) Cria perguntas de desenvolvimento baseadas num tema específico.
study_plan_generator(topic) Cria planos de estudo personalizados com base nos materiais disponíveis.
generate_lesson_summary(topic) Gera resumos automáticos de lições ou documentos.
interactive_flashcards(topic) Cria cartões interativos de revisão para estudo autónomo.
generate_test(topic) Cria testes avaliativos com diferentes níveis de dificuldade.
